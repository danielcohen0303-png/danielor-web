# תבנית אתר סרט גלילה

התבנית שממנה בונים אתר ״סרט גלילה״: גוללים, והסרט זז עם האצבע, סצנה אחרי סצנה. היא חלקה באייפון וגם מתוך אינסטגרם.

איך בונים, וכל הלקחים: הסקיל **`scroll-film-site`** (`~/.claude/skills/scroll-film-site/`).

## בקצרה
1. **מעתיקים את התבנית לתיקייה חדשה,** בלי `node_modules`, `.git`, `.vercel` ו-`public/film/*`. אחר כך `npm ci`.
2. **כל ההתאמה ב-`src/site.config.ts`:** שם, קול, פרטי קשר, פרטים משפטיים, צבעים, טופס, סצנות, ״על״ ושאלות.
3. **מדיה לכל סצנה:**
   ```bash
   bash scripts/media/build-film.sh media-src/<scene>.mp4 <scene> v1
   ```
4. **בדיקות:**
   ```bash
   python3 scripts/qa/film.py <url>
   python3 scripts/qa/pages.py <url>
   python3 scripts/qa/form.py <url>
   ```
5. **פריסה:**
   ```bash
   npx vercel deploy --prod --yes --scope team_fPPPT7eZCBNAryq3ZNb1fleH
   ```

## חוקי הטלפון (Danielor, 02.11)
נלמדו באייפון של דניאל. כבר בתוך המנוע, ונשמרים בכל אתר חדש מהתבנית:
- **ההורדה מקדימה את הקורא.** בטלפון כל סצנה מתנגנת מקובץ וידאו שלם, ועד שהוא מגיע רואים תמונה עומדת. לכן כל הסצנות מתחילות לרדת עם פתיחת הדף, אחת אחרי השנייה לפי סדר הסרט (`AssetLoader.keep` ב-`OneFilm`). אם הסרט כבד מדי להורדה מלאה (מעל כ-80MB לטלפון), צריך קובצי טלפון קלים יותר, לא חלון הורדה קצר.
- **מה שלא על המסך לא קיים.** אלמנט שמחכה לרגע שלו מקבל `display: none` ולא `visibility: hidden`, ובלי `will-change` כשהוא לא זז. כך הוא לא מחזיק שכבה גרפית. באייפון שכבות כאלה ממלאות את זיכרון הגרפיקה ותוקעות גם את מה שעל המסך.
- **אין שום דבר שנצבע מחדש בכל פריים.** לא SVG במסך מלא שמשתנה עם הגלילה, ולא קווים שמחושבים מחדש. ציור חד-פעמי משאירים לדפדפן (transition), ואז הוא נח.
- **פילטרים קלים בטלפון.** בטלפון לא משרשרים יותר משלושה `drop-shadow`. כשהטקסט התיישב, `filter: none` (גם `blur(0px)` עולה). אין טשטוש על דברים בתנועה.
- **לא יותר מווידאו אחד שמתנגן מעל הסרט בטלפון.** בטלפון מציגים תמונה (`data-wide-only`).
- **בודקים את הגלילה הראשונה.** בודקים בקישור טרי, בטלפון מדומה עם מעבד מואט פי 4, וסופרים פריימים. כדי לבדוק בטלפון אמיתי שולחים את הקישור הקבוע של הענף, כדי שהמטמון יישמר בין גרסה לגרסה.
